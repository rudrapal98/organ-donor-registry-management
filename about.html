About This Project

Project Description

The Organ Donor Registry Management System is a lightweight, offline web application for recording and managing organ donors and organ recipients. It lets an operator register donor and recipient details, view them in clear tables, edit or delete records, and search the donor registry by name, blood group or organ. All information is kept on the user's own device using the browser's localStorage, so the project runs entirely in the browser without any server, database or internet connection.

Objectives
  • Maintain a simple, searchable registry of organ donors.
  • Maintain a registry of organ recipients awaiting a transplant.
  • Provide full create, read, update and delete (CRUD) operations.
  • Validate user input so records stay clean and consistent.
  • Work completely offline with no installation or backend server.
  • Offer a clean, responsive and professional user interface.
Technologies Used
  • HTML5 — page structure and forms.
  • CSS3 — custom styling and the blue theme.
  • Vanilla JavaScript — application logic and validation.
  • Bootstrap 5 (bundled locally) — responsive layout and components.
  • Browser localStorage — client-side data storage.
